# 贵州口音 ASR 评测展示页设计

## 目标

在现有 HTTPS 网关中提供一个独立页面，集中展示本轮 26 条贵州口音测试音频、人工参考文本和科大讯飞转写结果，便于逐条试听和复核识别效果。

页面固定访问地址：

`https://192.168.173.167:8443/guizhou-eval.html`

## 范围

- 展示本轮已成功完成评测的全部 26 条音频。
- 顶部展示样本数、严格 CER、完全匹配率、平均音频时长和平均识别耗时。
- 支持“全部、完全正确、存在错误”三种筛选。
- 每条样本展示编号、音频播放器、参考文本、科大讯飞转写、字符错误数、单条 CER、识别耗时和请求次数。
- 参考文本与转写结果中的差异字符使用颜色高亮。
- 不修改 ASR 通话、模型切换或后处理逻辑。
- 不新增动态后端接口。

## 文件与数据流

新增以下静态资源：

- `web/guizhou-eval.html`：页面结构、样式和交互。
- `web/guizhou_eval/results.json`：26 条评测结果和汇总指标，不包含密钥或签名 URL。
- `web/guizhou_eval/audio/*.mp3`：26 条测试音频。

现有 `https_gateway.py` 已将 `web/` 注册为根静态目录，因此无需更改网关路由。浏览器打开页面后加载相对路径下的 JSON，再为每条记录创建播放器和结果卡片。

## 页面行为

页面首次加载显示汇总指标和全部样本。筛选仅在浏览器本地执行，不发起额外业务请求。字符差异由页面按 Unicode 字符计算编辑对齐，删除、插入和替换分别标记，标点与空格不计入 CER 和差异统计。

音频不能加载时，对应卡片显示“音频加载失败”，其他样本仍可使用。结果 JSON 加载失败时，页面显示明确错误信息，不渲染空白页面。

## 验证

- 校验 JSON 恰好包含 26 条唯一记录。
- 校验每条记录对应的 MP3 文件存在且非空。
- 校验汇总编辑数、参考字符数、CER 和完全匹配数能由明细重新计算得到。
- 校验 HTML 中不存在凭据、签名鉴权地址和外部运行时依赖。
- 通过现有 HTTPS 网关访问页面并抽查音频播放、筛选及高亮。
